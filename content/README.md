# content/ — xom kontent (siz to'ldirasiz)

Har bir `.txt` faylda namuna bor. `#` bilan boshlangan qatorlar izoh — ularni o'chirmasangiz ham bo'ladi.
Bloklar orasini bitta bo'sh qator bilan ajrating. Bilmagan maydoningizni bo'sh qoldiring — sayt placeholder ko'rsatadi.
Til: o'zbekcha yoki inglizcha yozavering, ikkinchisini men tarjima qilaman (TRANSLATIONS.md da belgilayman).

Rasmlar: JPG/PNG/WebP, iloji boricha katta o'lchamda. Fayl nomi .txt dagi `image:` / `logo:` / `screenshot:` bilan bir xil bo'lsin.

⚠️ Repo GitHub'da ochiq bo'lsa, bu yerga qo'ygan har bir fayl hammaga ko'rinadi.
Offer letter rasmlarida maosh, manzil, telefon, ID raqam yoki imzo bo'lsa — avval menga ayting.
